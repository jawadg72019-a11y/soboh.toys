# Soboh Toys – عرض سعر إدارة سوشال ميديا كامل

عرض سعر شهري مقدّم من Jawad Almohor.

الملف الرئيسي: `index.html` (صفحة واحدة ثابتة، بدون أي ملفات إضافية).

## النشر على GitHub Pages
1. ارفع الملفين `index.html` و `README.md` إلى مستودع جديد.
2. من **Settings → Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO-NAME/`
